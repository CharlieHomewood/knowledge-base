A probability density function (PDF) is a function associated with a [[Random Variable|continuous random variable]] that assigns a probability density to each possible value that variable can take.

As the values drawn from continuous random variables are [[Real Numbers|real-valued]], the probability of an exact value $x$ is always $0$. Instead, we consider the probability that the value falls within some interval $[a,b]$ by calculating the area below the PDF curve over that interval.

## Notation

A PDF can be denoted in the following form and:

$$
\int_{-\infty}^{\infty}f(x)\,dx=1
$$

For some interval $[a,b]$, the probability that a value drawn from a continuous random variable $X$ falls between that interval is given by:

$$
P(a \le X \le b)=\int_{a}^{b}f(x)\,dx
$$
