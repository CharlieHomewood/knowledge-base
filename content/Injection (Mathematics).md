Injection refers to a function which maps every element in [[Set|set]] $A$ to one, and only one, element in set $B$. 

Injection from set $A$ to set $B$ is possible if and only if the [[Cardinality|cardinality]] of set $A$ is less than or equal to the cardinality of set $B$. Thus, $B$ can contain more elements than $A$ and still allow for injection from $A$ to $B$:

$$
|A| \le |B|
$$

## Notation

We can define injection as the case when no two elements in set $A$ map to the same element in $B$:

$$
\forall a_{1},a_{2} \in A,~~~~~a_{1} \neq a_{2} \implies f(a_{1}) \neq f(a_{2})
$$
