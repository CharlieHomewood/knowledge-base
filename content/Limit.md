The limit is a value which a function approaches as the index of that function approaches a particular value. 

Limits help to analyse the behaviour of functions in cases when directly substituting a value results in the function being undefined.

## Notation

We denote the limit $L$ of a function $f(x)$ as the value of $x$ approaches some value $c$ as follows:

$$
L=\lim_{x\to c}f(x)
$$
