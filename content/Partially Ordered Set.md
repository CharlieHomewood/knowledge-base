A partial ordered [[Set|set]] is a set where specific pairs of elements can be ordered, but not the entire set.

## Properties

For some set $P$, we can define the following properties such that $P$ is partially ordered.

### Reflexivity 

$$x \le x\quad\forall x \in P$$

### Antisymmetry

$$x \le y \,\land\, y \le x \,\rightarrow\, x=y$$

### Transitivity 

$$x \le y \,\land\, y \le z \,\rightarrow\, x \le z$$
