The Gaussian function is a mathematical function which, in its simplest terms, takes the form $e^{-x^{2}}$

This function is involved in the [[Probability Density Function|probability density function]] of the [[Normal Distribution|normal distribution]].

## Notation

A Gaussian function $f(x)$ takes the form:

$$
f(x)=ae^{\displaystyle-\frac{(x-b)^{2}}{2c^{2}}}
$$

Where:

 - $a$ determines the maximum height of the function
 - $b$ determines the $x$-axis value of the centre point of the function
	 - In a normal distribution, this is the [[Arithmetic Mean|mean]] or [[Expectation Value|expected value]].
 - $c$ determines the width of the function
	 - In a normal distribution, this is the [[Standard Deviation|standard deviation]]
