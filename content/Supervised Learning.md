Supervised learning refers to a type of [[Machine Learning|machine learning]] [[Algorithms|algorithm]] where a model is trained on a dataset with some pre-existing labels which can be used to inform the model (via a [[Loss Function|loss function]]) of how to most optimally map input data to correct output values.

The general task, therefore, for supervised learning algorithms is to find optimal model parameters which minimise some loss function by using examples of correct pairs of input and output data.
