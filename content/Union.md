The union of two [[Set|sets]] $A$ and $B$ is the set of all the elements in $A$ and all the elements in $B$. 

If there are duplicated elements between $A$ and $B$, only one instance of these duplicated elements is added to the union.

## Notation

For two sets, we can define their union as all the set of all elements that are either in $A$ or in $B$. This is denoted as follows:

$$
A \cup B=\{x:x\in A \lor x \in B\}
$$

For $n$ sets $A_{1},\dots,A_{n}$, their union is denoted as:

$$
\bigcup_{i=1}^{n}A_{i}=A_{1}\cup A_{2} \cup \dots \cup A_{n-1} \cup A_{n}=\{x ~|~ \exists i \in \{1,\dots,n\} ~|~ x \in A_{i}\}
$$
