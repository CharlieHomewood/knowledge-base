The learning rate in a [[Machine Learning|machine learning]] [[Algorithms|algorithm]] refers to a type of [[Hyperparameter|hyperparameter]] used to determine the step size of each iteration of a [[Gradient Descent|gradient descent]] algorithm used to optimise a [[Loss Function|loss function]].

This value is often manually chosen, but [[Adaptive Algorithms|adaptive methods]] can also be used to decide on an optimal value.

## Notation

The learning rate is usually denoted $\eta$.
