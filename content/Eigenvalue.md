For some [[Vector|vector]] $v$, if when [[Matrix Multiplication|multiplied]] with a [[Square Matrix|square matrix]] $A$, the elements of the vector are simply scaled by some value [[Scalar|scalar]] value $\lambda$, then the vector is called an [[Eigenvector|eigenvector]].

The value of $\lambda$ which provides such a scaling to an eigenvector is the eigenvalue of that eigenvector.
