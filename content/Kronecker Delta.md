The Kronecker delta is a function used to compare equality between two variables. If they are equal, the function returns $1$, otherwise it returns $0$.

## Notation

For two variables $i$ and $j$, the Kronecker delta is defined as such:

$$
\delta_{ij}=
\begin{cases}
0\quad\text{if }i \neq j \\[10pt]
1\quad\text{if }i=j
\end{cases}
$$
