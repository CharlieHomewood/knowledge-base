A probability mass function (PMF) is a function associated with a [[Random Variable|discrete random variable]] that assigns a probability mass to each possible value that variable can take.

## Notation

A PMF of a discrete random variable $X$ with support $[a,b]$ can be denoted in the following form and:

$$
\sum_{x\in X[a,b]}f(x)=1
$$

For some particular value $x$ drawn from $X$, the probability of that value can be given by:

$$
P(X=x)
$$
