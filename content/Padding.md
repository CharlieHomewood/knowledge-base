Padding refers to a technique used in [[Convolutional Neural Network (CNN)|convolutional neural networks]] to avoid a [[Convolution Matrix|kernel]] failing to appropriately capture the border elements of an input [[Matrix|matrix]] when [[Convolution|convoluted]] with it.

Along with helping to process the border elements of the input matrix, padding can also be used to ensure the outputted feature map from a convolutional layer has the same dimensions as the input matrix.
