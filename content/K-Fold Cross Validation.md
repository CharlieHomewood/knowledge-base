K-fold cross validation is a method for splitting a dataset into $k$ equally-sized parts and training a [[Machine Learning|machine learning]] model multiple times where each part is used as the test dataset. 

The model performance metrics from each iteration are then averaged to provide an overall set of model performance metric estimates, with an associated [[Variance|variance]].
