Latent semantic analysis is a method used in [[Natural Language Processing|natural language processing]] to reduce the dimensionality of a [[Document-Term Matrix|document-term matrix]] by using [[Singular Value Decomposition|singular value decomposition]] to return a [[Matrix|matrix]] with fewer rows, whilst preserving the similarity between columns. 

This lower-dimensional matrix represents the underlying similarities in the meaning of different words, based on the assumption of [[The Distributional Hypothesis|the distributional hypothesis]].
