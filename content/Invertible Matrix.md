An invertible matrix is a [[Square Matrix|square matrix]] $A$ which can be multiplied by some other square matrix $B$ to yield an [[Identity Matrix|identity matrix]].

## Notation

If $A$ is an invertible matrix, then there exists some square matrix $B$ such that a [[Matrix Multiplication|matrix multiplication]] of $A$ and $B$ yields an identity matrix $I$:

$$
AB=BA=I_{}
$$

## How to Determine if a Matrix is Invertible

If a square matrix $A$ is invertible, then its [[Determinant|determinant]] will **not** be equal to $0$
