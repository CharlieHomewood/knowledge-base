Bijection is a function which forms a one-to-one correspondence between every element in one [[Set|set]] $A$ with every element in another set $B$. 

## Properties

A bijective function must have the following properties:

1. It must be [[Injection (Mathematics)|injective]]
2. It must be [[Surjection|surjective]]

The [[Cardinality|cardinality]] of set $A$ must equal the cardinality of set $B$ in order for bijection between $A$ and $B$ to be possible. 

## Notation

With the two necessary properties, we can define bijection as a function which is both injective and surjective. We would express this definition symbolically as follows:

$$
\forall a_{1},a_{2} \in A,~a_{1} \neq a_{2} \implies f(a_{1}) \neq f(a_{2}) ~~~\land~~~ \forall b \in B, \exists a \in A ~|~ f(a)=b
$$

The part before the $\land$ (the mathematical symbol for "and") defines the property of injection, and the part following $\land$ define surjection.
