Ordinal data refers to a type of data which consists of [[Integers|integer]] values which have a coherent ordering, but notions of how much larger of smaller a given value is to another is not defined.

For example, positions in which football teams finish in a league table would be ordinal data: we can order these teams in descending order starting with the $1^{st}$ positioned team, and so on. It is not the case that the team in position $1$ is $x$-times more "positioned" than the team in position $8$. instead the teams are simple being ranked by the position data point.
