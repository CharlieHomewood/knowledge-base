Good-Turing frequency estimation is a technique for estimating probabilities of events from some unseen category given some set of events from an observed category.

## Applications

Some common applications of Good-Turing frequency estimation are:

 -  [[N-gram Model Smoothing|N-gram model smoothing]], wherein the technique is referred to as [[Good-Turing Smoothing|Good-Turing smoothing]].
