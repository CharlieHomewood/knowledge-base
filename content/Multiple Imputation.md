Multiple imputation is a method for handling missing data in a dataset. This method is useful when applied to features for which only a minority of instances have missing values.

Unlike [[Unit Imputation|unit imputation]], rather than imputing a single value for an instance of missing data, multiple values are drawn from a [[Probability Distribution|distribution]]
