Overfitting is an issue in [[Machine Learning|machine learning]] whereby a trained model too closely aligns to training data and fails to appropriately generalise to unseen data.

## Techniques to Reduce Overfitting 

Additional model complexity should only be permitted if there is sufficient statistical justification. This approach reflects [[Parsimony|parsimony]], whereby models should be kept as simple as possible, all else equal.

[[Regularisation]] is one method for reducing overfitting, which involves adding a penalty term to a [[Loss Function|loss function]] during training.
