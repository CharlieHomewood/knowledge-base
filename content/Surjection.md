Surjection is a function which maps elements from set $A$ to set $B$ such that every element in $B$ is paired with at least $1$ element in $A$. Thus, with surjection, elements in $B$ can be paired with more than one element in $A$, but not vice-versa.

## Notation

To define surjection, we can say that for every element in $B$, there exists an element in $A$ such that there is function which maps at least one element in $A$ to that element in $B$ and only that element in $B$:

$$
\forall b \in B, \exists a \in A ~|~ f(a)=b
$$
