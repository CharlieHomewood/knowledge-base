Linear regression is a [[Supervised Learning|supervised]] [[Machine Learning|machine learning]] [[Algorithms|algorithm]], used for continuous-output prediction tasks.

## Formula 

For some vector of continuous outputs $\mathbf{\hat{y}}$, we can predict its value by taking the [[Feature Space|set of features]], weighing them by some set of optimal weights $\mathbf{w}$ and adding some vector of bias terms $\mathbf{b}$. Such an operation produces a straight-line equation for each data point, mapping its feature values to some predicted continuous output value.

$$
\mathbf{\hat{y}}=\mathbf{w}\mathbf{x}+\mathbf{b}=w_{1}x_{1}+b_{1}+\dots+w_{i}x_{i}+b_{i}+\dots+w_{n}x_{n}+b_{n}
$$
