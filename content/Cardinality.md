Cardinality refers to the number of elements in a [[Set|set]].

Two sets have the same cardinality if there exists a one-to-one correspondence (i.e. [[Bijection|bijection]]) between the elements of each set. Two sets with the same cardinality are equinumerous sets.

If the cardinality of a set is less than or equal to the cardinality of the [[Natural Numbers|natural numbers]], that set is [[Countable Set|countable]]. If the cardinality is greater than that of the natural numbers, the set is [[Uncountable Set|uncountable]].

## Notation

The cardinality of a set $A$ is denoted $|A|$
