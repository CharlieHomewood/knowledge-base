Model parameters are values in a [[Machine Learning|machine learning]] model which are learned during training and determine how the model makes predictions $\hat{y}$ from [[Feature Space|features]] $X$.

## Notation

In general, arbitrary model parameters are denoted using $\theta$, but the symbols used depend on the context and type of model being used. 

 - For instance, in [[Linear Regression|linear regression]], we have parameters $w$ and $b$, which are the weights and bias term of the linear model.
