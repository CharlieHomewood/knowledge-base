Recall is a metric used to evaluate the performance of a [[Classification Algorithms|classification]] [[Machine Learning|machine learning]] [[Algorithms|algorithm]], defined as the proportion of [[True Positives|true positives]] to the number of actual positives.

Recall is also known as the true positive rate (TPR) or the sensitivity.

## Notation 

The recall of a model is given by the ratio between the number of true positives $TP$ and the total number of actual positives (i.e. true positives + [[False Negatives|false negatives]]) $TP+FN$:

$$
\text{recall}=\frac{TP}{TP+FN}
$$
