A probability distribution is a function which describes the probability of possible values which could be drawn from a [[Random Variable|random variable]].

The functions used to outline a probability distribution are:

 - [[Cumulative Distribution Function]]
 - [[Probability Density Function]]
 - [[Probability Mass Function]]

## Discrete Distributions

Discrete distribution describe the probability distribution of discrete random variables.

Discrete distributions assign probability mass to each possible value a discrete random variable can take. The probability of a value is therefore just the probability mass of that value.

## Continuous Distributions

Continuous distribution describe the probability distribution of continuous random variables.

Discrete distributions assign probability density to each possible value a continuous random variable can take. Probabilities are then calculated by considering the area below the curve of the probability density function between some interval.
