The set difference of some [[Set|set]] $A$ with some set $B$ is the set of all the element in $A$ which are not present in $B$. 

It is equivalent to the [[Complement#Relative Complement|relative complement]] of $A$, with respect to set $B$.

## Notation

We denote the set difference of set $A$, with respect to set $B$ as follows:

$$
A~\backslash~B = \{x \in A~|~x \notin B\}
$$
