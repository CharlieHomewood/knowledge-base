The power set of a [[Set|set]] $A$ is the set of all possible subsets of $A$, including the empty set and $A$ itself.

## Notation

The power set of $A$ is denoted:

$$
\mathcal{P}(A)
$$

The number of possible subsets of a set $A$ with $n$ elements (the [[Cardinality|cardinality]] of $A$) is equal to $2^{n}$:

$$
|\mathcal{P}(A)|=2^{n}~~~~~\text{where }|A|=n
$$
