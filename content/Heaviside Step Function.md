A Heaviside step function is a function which maps [[Real Numbers|real-valued]] inputs to $1$ if they are positive, otherwise to $0$.

## Formula

For some real number $x$, the Heaviside step function $H(x)$ is given by:

$$
H(x)=\begin{cases}1&x>0\\0&x\le0\end{cases}
$$
