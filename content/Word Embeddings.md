A word [[Embedding|embedding]] is a fixed-dimensional [[Vector|vector]] representation of a word used in [[Neural Network|neural networks]] for [[Natural Language Processing|natural language processing]] tasks.

For some set of words in a corpus, we can consider each of their word embedding vectors as a row in an embedding [[Matrix|matrix]]. The values of this embedding matrix are therefore a set of parameters learned by the neural network during training.
