Logarithmic identities are a collection of rules which help solve logarithmic expressions.

## List of Logarithmic Identities 

| Rule           | Formula                                                                                                  |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| Product Rule   | $$\log_{b}(xy)=\log_{b}(x)+\log_{b}(y)$$                                                                 |
| Quotient Rule  | $$\log_{b}\left(\frac{x}{y}\right)=\log_{b}(x)-\log_{b}(y)$$                                             |
| Power Rule     | $$\log_{b}(x^{a})=a\log_{b}(x)$$                                                                         |
| Change of Base | $$\log_{b}(a)=\frac{\log_{k}(a)}{\log_{k}(b)}$$                                                          |
| Summation Rule | $$\log_{b}\sum_{i=0}^{N}a_{i}=\log_{b}(a_{0})+\log_{b}\left(1+\sum_{i=1}^{N}\frac{a_{i}}{a_{0}}\right)$$ |
