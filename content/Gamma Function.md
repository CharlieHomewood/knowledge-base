The gamma function is a generalisation of the factorial function to [[Complex Numbers|complex number]].

## Formula

For a positive [[Integers|integer]] $n$, the gamma function is given by:

$$
\Gamma(n)=(n-1)!
$$

For a complex number with a positive [[Real Numbers|real number]] part $z$, we can use the following [[Integral|integral]]:

$$
\Gamma(z)=\int_{0}^{\infty}t^{z-1}e^{-t}\,dt
$$
