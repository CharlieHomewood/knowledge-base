Numeric data is a [[Data Types|data type]] which represents numbers.

## Types

### [[Boolean Data|Boolean]]

Boolean values are a type of numeric data, since they can be represented by $0$ for false and $1$ for true.

### Floating-Point Numbers 

Floating-point numbers are used to represent [[Real Numbers|real numbers]] as a significand multiplied by some base (usually base $2$) raised to some power.

### [[Integers]]

Integers represent whole numbers (both positive and negative).
