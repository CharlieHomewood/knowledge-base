The complement of a [[Set|set]] $A$ is simply the set of all elements which are not in $A$.

On face value, this would appear to mean the complement of any set is every single possible element in existence which is not in $A$, but this is not the case. 

We instead consider some universal set $U$ which contains all the elements under consideration in a given context and see which elements in $U$ are not in $A$. Therefore, the complement of $A$ is always relative to some universal set $U$. This is known as the absolute complement.

We can also consider the relative complement of $A$, which is all the elements in $B$ which are not in $A$. This is also called the [[Set Difference|set difference]].

## Notation

### Absolute Complement

The absolute complement of $A$, denoted $A^{c}$ is defined as:

$$
A^{c}=U~\backslash~A=\{x \in U : x \notin A\}
$$

### Relative Complement

The relative complement of $A$, with respect to set $B$, is defined as:

$$
A^{c}=B~\backslash~A=\{x \in U : x \notin B\}
$$
