A long short term memory (LSTM) [[Neural Network|neural network]] is a variant of [[Recurrent Neural Network (RNN)|recurrent neural network (RNN)]] which modifies the standard RNN architecture to improve its ability to capture long-range dependencies which are often lost in standard RNNs.
